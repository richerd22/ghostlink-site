                        OSC OUT (LIGHTS / VISUALS)
                        
    
                        
      
      
                        
      
                        Every beat, BPM, section and the on-air track as raw OSC. 
                        
      
                        /ghostlink/beat (i beat, f bpm, i deck), /ghostlink/downbeat, /ghostlink/bpm, /ghostlink/phrase (s section), /ghostlink/onair (s title, s artist), /ghostlink/deck/N/beat, /ghostlink/next, /ghostlink/drop, and DECK CONTROLS presses as /ghostlink/control (s stopall/stop/play/load, i deck). For Resolume, TouchDesigner, MadMapper, QLC+, lighting desks.

                        A booth TV, a stream, the crowd, the box's sticker. 
                        
    
                        TV MODE: a booth screen or projector (tap for full screen). STREAM OVERLAY: now playing for OBS or any browser source (lower third, corner ticker, big card, BPM + key, played before); pick the look and COPY LINK, plus HIDE IDS and START STREAM CLOCK for the setlist. CREW SCREEN: a screen to leave on for the crew: MUSIC OFF countdown (the HOLD while one is up), who's on with the weather line, who's next with their set note, the next drop, the DOOR COUNT, crew calls; no track titles. STAGE CLOCK: for an LED wall or a monitor the DJ can see: time left in the set (amber at 10 min, red at 5, over in red), when it ends, who's on and next, the changeover, the time, WRAP-UP CALLS (also tv.html?clock=1); tap it for HOLD (crew code). STAGE CLOCK SIDEWAYS: the same for a screen mounted on its side (?rotate=90; R on its keyboard turns it again). NEXT UP: the stage clock for the crowd: who's on, who's next and when, the changeover countdown; no crew lines (add ?weather=1 for the wind line). WHAT'S ON: see-through text for a stream (who's on, who's next; the track only while SONG ID is on; ?size=48); /api/whatson?format=text for chat bots. SONG PAGE: what's playing for the room (turn it on under TONIGHT -> SONG ID). PRINT STICKER: the box's Wi-Fi and address as a QR. VISUALIZER: TV MODE as a full-screen picture of the music for a spare screen (tv.html?vis=1). NOW PLAYING: a lock-screen style card for a phone (art, title, time left; KEEP AWAKE).

                          WHERE THINGS ARE
                          
    
                          
      
                          STATUS, top
                          READY FOR TONIGHT (the one thing to fix first, then anything worth a look), GO TO (type wifi, record, venue... and it opens there), BOOTH CHECK, warnings, the lock.
                          
      
                          STATUS → TONIGHT
                          NIGHTS (plan a lineup, set notes after a name, SET TIMES FROM A SHEET), DECK CONTROLS (stop all, AUTO-STOP at music off), ANNOUNCEMENTS, SONG ID FOR THE CROWD, NIGHT SAFETY (SHOW STOP, HOLD, CURFEW LADDER, DOOR COUNT, WEATHER), ASK THE DJ, WANTLIST.
                          
      
                          STATUS → THIS VENUE
                          VENUE (+ MUSIC AT THIS VENUE), WI-FI, ROOMS.
                          
      
                          STATUS → SCREENS & OUTPUTS
                          SHOW CONTROL (Link, MIDI clock, Resolume, grandMA3, QLab, VISUALS LINK), OSC OUT, LIGHTS, SCREENS (TV mode, stream overlay, crew screen, stage clock, next up, song page, sticker), WATCH FROM HOME, SHARE, API KEYS.
                          
      
                          STATUS → THE BOX
                          CONTROLS (rejoin, listen only, restart, shut down), BACKUP (+ black box, logs), UPDATES (check, install, from a file, go back), BOX DETAILS, TOOLS (demo, tour, arcade, test run).
                          
      
                          NETWORK
                          Devices, MIXER (USB MIDI), SOUND IN + SET RECORDINGS, EVENTS.
                          
      
                          Keys (laptop)
                          1-6 or ← → switch tabs (on a phone: swipe the page sideways), / opens GO TO, Esc closes it, R = READY FOR TONIGHT, P = plan tonight. The page opens on the tab you used last.
                          
      
                          Links
                          Add a place to the address to open it: #status/venue, #status/wifi, #network/sound, #now/vj.

                          SCREENS
                          
    
                          
      
                          NOW
                          One big readout of what's on air. Pick who you are: DJ (set time left, next DJ, the other deck), PHOTO (big drop countdown), VJ and LIGHTS (section, next, bars to the drop, show control), SOUND (sound-in level, room dB), TECH (box health), MANAGER (the night in numbers, lineup), HOST (who's on next, music off). EDIT to show or hide anything. Saved on this phone. Share a role: add ?role=photo to the address. ALL DECKS shows every deck on one screen.
                          
      
                          DECKS
                          Every player: track, art, BPM, pitch, time left, key, waveform, song sections (intro, up, chorus, down...) when rekordbox has phrase analysis, and a beat counter.
                          
      
                          NETWORK
                          Everything on the DJ network and how busy it is. GHOST LINK sits on a number 7-15 and never takes a player's number.
                          
      
                          PLAYED
                          Every track that was on air 10+ seconds. Past nights, recap numbers, BPM across the night, CSV/JSON, a recap image to post, and END OF NIGHT: one card per night with MUSIC OFF kept or not. ON THE DECKS: type the next DJ and SET at each changeover; tracks get grouped by DJ.
                          
      
                          STATUS
                          Health, then four groups: TONIGHT, THIS VENUE, SCREENS & OUTPUTS, THE BOX. GO TO at the top finds any setting. Watching is open to anyone; changing anything needs the password once per phone. LISTEN ONLY never needs it. VENUE keeps address, rooms, gear, contacts and venue Wi-Fi (the box joins it by itself). NIGHTS: plan a date, venue and lineup with times; on the night it switches by itself.
                          
      
                          Share the dashboard
                          Tap GHOST LINK at the top: the address on this network, a QR code and COPY. Off-site: gl.cold.fyi.
                          
      
                          Share links
                          STATUS → SHARE (owner): NEW LINK gives someone a link instead of the password, doing only what you tick (WATCH, CREW CALLS, STOP / START THE DECKS, SETTINGS), until the end of the night unless you choose longer. REVOKE ends one at once; REMOTE OFF refuses them from outside the venue, or all of them.
                          
      
                          ghostlink.local doesn't open
                          Some phones or guest Wi-Fi don't support it. Tap GHOST LINK at the top for the number address and QR, or use the GHOST LINK Wi-Fi (10.42.0.1).
                          
      
                          Watch from home
                          STATUS → WATCH FROM HOME → TURN ON (box on a Wi-Fi with internet). Send the link; it's view only. TURN OFF ends it.
                          
      
                          Rooms
                          More than one box? STATUS → ROOMS: name this room, list the others (e.g. 51 = ghostlink-51.local). NOW shows them all.
                          
      
                          Mixer FX
                          USB cable from the DJM's USB port to the box (venue's OK first). NETWORK → MIXER: touch a control, NAME it, WATCH it for FX LEFT ON warnings. Listen only.
                          
      
                          PLAYED / MIX tags

                          TV mode / stream
                          STATUS → SCREENS → TV MODE for a booth screen or projector (tap for full screen). STREAM OVERLAY: pick the look, COPY LINK, paste it into an OBS Browser source.

                          IF SOMETHING'S WRONG
                          
    
                          
      
                          BACKED OFF
                          Another device used our number. GHOST LINK stepped aside and comes back on a free number in about 30 seconds. Nothing to do.
                          
      
                          No DJ Link data
                          Cable on the wrong switch, or the gear is in laptop/controller mode (Serato, rekordbox USB-to-laptop). Players must be in standalone/LINK mode.
                          
      
                          No DJ cable
                          Cable out or switch off. Plug it back; it recovers in seconds.
                          
      
                          Two players, one number
                          On one player: Menu/Utility → PLAYER No. → a free number.
                          
      
                          No titles, only BPM
                          LISTEN ONLY is on, or GHOST LINK is backed off. STATUS → REJOIN.
                          
      
                          Can't reach the box
                          Phone on a different Wi-Fi. Join the box's Wi-Fi, or scan the sticker (STATUS → SCREENS → PRINT STICKER).
                          
      
                          USB OUT
                          The USB or SD card a playing track comes from is being pulled. The track keeps going; plug it back before loading the next one.
                          
      
                          Anything weird
                          STATUS → LISTEN ONLY. The box goes quiet on the DJ network. Last resort: pull the power; nothing breaks.
                          
    
                          
    
                          Every change and problem is in NETWORK → EVENTS and in STATUS → BACKUP → LOGS.
