USING GHOST LINK WITH OBS

Now playing on your stream: a lower third, a corner ticker or a big card, as an OBS Browser source. Pick the look on the box, copy the link, paste it.

SET IT UP

  1. The streaming computer on the same Wi-Fi as the box.

  2. On the dashboard: STATUS → SCREENS → STREAM OVERLAY. It opens the overlay's page.

  3. Pick the look. The preview shows it live, or with made-up tracks when nothing is playing.

  4. Tap COPY LINK.

  5. In OBS: Sources → + → Browser. Paste the link into URL. Width 1920, height 1080 (or 1280 and 720).

THE LOOKS

  • LOWER THIRD: cover, title, artist and the DJ's name in a corner. Slides in on a new track; stays up, or fades after 10, 20 or 30 seconds.
  • CORNER TICKER: one small line. BIG CARD: the middle of the screen.
  • Add a BPM + KEY chip, the tracks PLAYED BEFORE, and a TIME BAR (a line or the track's waveform).
  • KEY AS: the key the way rekordbox shows it, as a musical key (Am) or as Camelot (8A).
  • Laptop DJ, no decks on the network: the chip shows the BPM the box hears from the sound card, marked BY EAR.
  • See-through by default; GREEN SCREEN or BLACK for apps that need one.
  • Nothing playing: nothing on screen.

TITLES AND IDS

  • Titles show only while SONG ID is on. Off, the overlay shows the DJ's name and the BPM. The tracklist is the DJ's: turn it on only when the DJ says yes.
  • HIDE IDS: tap HIDE next to a track (on the overlay's page, or in PLAYED) and it shows as ID - ID. While it's on, NOW also offers HIDE NEXT for the track loaded on the other deck, before it ever shows. Tracks with "unreleased" in the title, artist or comment are hidden by themselves. The box remembers them for every night.

THE SETLIST FOR YOUR VIDEO

Tap START STREAM CLOCK when the stream goes live. COPY SETLIST then gives "00:00 Artist - Title" lines that match the video, ready for a description. Without it, the times count from the recording or the first track.

Stream running a few seconds behind (an OBS delay, the platform's lag)? +5 S moves every chapter 5 seconds later; −5 S earlier.

FOR OTHER TOOLS

Plain feeds on the box: /api/nowplaying.txt (one line), /api/nowplaying.json and /api/setlist.txt. Same rules as the overlay. WHAT'S ON (/whatson.html) still gives who's on and who's next.

OBS TEXT SOURCE (READ FROM FILE)

OBS's Text source reads a file on the computer, not a link. The Browser source above is the easy way. If you want a Text source anyway, keep a file up to date on the Mac: open Terminal and leave this running (Ctrl-C stops it).

while true; do curl -sf -m 2 http://ghostlink.local/api/nowplaying.txt -o ~/nowplaying.tmp && mv ~/nowplaying.tmp ~/nowplaying.txt; sleep 2; done

Then in OBS: Text → Read from file → pick nowplaying.txt in your home folder. If the box can't be reached, the file keeps its last line. A box with another name: use that name or its address.

TURN IT OFF

Hide the source in OBS (the eye), or delete it. GHOST LINK sends nothing to OBS and never changes its settings or scenes.
