USING GHOST LINK WITH OBS

For a stream: a see-through now-playing card and a who's-on line, as OBS Browser Sources.

WHAT IT GIVES OBS

  • STREAM OVERLAY: art, title, artist and BPM of what the room hears, in a corner. Fades on a new track.
  • WHAT'S ON: see-through text with who's on and who's next (the track only while SONG ID is on).
  • GHOST LINK sends nothing to OBS itself: OBS just shows the page.

SET IT UP

  1. The OBS computer on the same Wi-Fi as the box.

  2. The address is the box's address plus /overlay.html (or /whatson.html), for example http://ghostlink.local/overlay.html. Tap GHOST LINK at the top of the dashboard for the box's address on this Wi-Fi.

  3. In OBS: Sources → + → Browser, paste the address, width 1920, height 1080.

  4. Options go on the end of the address: ?pos=br (corner: bl, br, tl, tr), ?scale=1.5, ?bpm=0 (no BPM), ?bg=green (green screen).

TURN IT OFF

Hide the source in OBS (the eye), or delete it. GHOST LINK never changes OBS's settings or scenes.

Made for an OBS Browser Source; not tried in OBS by us yet. The tracklist is the DJ's: show titles on a stream only when the DJ says yes.
