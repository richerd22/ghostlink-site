HELP / HOW TO

WORKS BESIDE

The GHOST LINK dashboard is a browser window. It sits in the corner of any screen, next to anything else with a window, and sends it nothing. That's the whole trick. No plug-in, no row, no setup on the other side.

So this list isn't "integrations". It's apps people already keep open in the booth or at the desk, where a small window with every deck in it, the bars to the drop and the crew calls is handy. If it has a window, GHOST LINK looks good next to it.

The apps GHOST LINK really sends something to (tempo, the bar, a cue on the drop) are listed under USING GHOST LINK WITH.

PUT IT IN THE CORNER

  1. On that computer, join the same Wi-Fi as the box and open the dashboard in a browser.

  2. Make the window small and park it in a corner. The decks fit themselves to the window (AUTO picks CORNER or SIDE by its size), or pick DECKS → LAYOUT → STACKED.

  3. Want the drop big? NOW → LIGHTS: the section, what's next and the bars to the drop.

Done with it: close the window. Nothing was sent, so there's nothing to undo.

THE LIST, SO FAR

  • AVOLITES TITAN. Titan reads the DJ's BPM from the Pioneer DJ network by itself (Linking PioneerDJ System to Titan in Avolites' manual): use that for tempo. GHOST LINK is the window beside it. Both can be on the DJ network at once; GHOST LINK moves out of the way if a player number clashes. Untested together.
  • MADRIX. The window beside it. We found no Ableton Link or MIDI clock input in MADRIX's help, so GHOST LINK can't set its tempo. Building your own: STATUS → OSC OUT sends the beat, BPM, the drop and crew calls as plain OSC to any computer; mapping that inside MADRIX is up to you, and untested.
  • QUICKSHOW, BEYOND and other laser software. The window beside it. We found no Ableton Link, MIDI clock or OSC tempo input in QuickShow, so its own beat detection stays as it is. If your laser software takes Ableton Link, the ABLETON LINK row would work: tell us if it does.
  • LIGHTING CONSOLES without a row: the window on the console's screen or a laptop beside it.
  • VJ APPS without a row: the window in a corner of the control screen.
  • REKORDBOX on the DJ's laptop: the other decks, in a corner, while they dig for the next track. (The box doesn't need rekordbox running.)
  • A SPREADSHEET, THE SET TIMES, THE GROUP CHAT. Also fine. We don't judge.

GHOST LINK never opens, edits or saves another app's show file, and sends nothing to any app unless you set up its row or list it under OSC OUT.

Want a real row for one of these? Tell us the app, the version and what it should do on the drop: hello@thirdpolararch.com.
