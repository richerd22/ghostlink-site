HELP / HOW TO

WATCH FROM HOME

  1. The box must be on a Wi-Fi with internet (the venue's, not its own). Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  2. STATUS → WATCH FROM HOME → TURN ON.

  3. Tap COPY LINK and send it.

People on that link see the decks live. They can't change anything. PLAYED stays hidden unless the DJ has said yes and you've shared the tracklist.

TURN OFF ends it. It also turns off after every restart.
