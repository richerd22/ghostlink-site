USING GHOST LINK WITH MADRIX

There's no ready-made MADRIX row yet. Here's what works today, honestly.

WHAT IT GIVES MADRIX

  • The dashboard in a small window beside MADRIX, so the operator sees the decks, the next drop and the crew calls: DECKS → LAYOUT → STACKED.
  • MADRIX's own help lists OSC and MIDI remote control and MIDI timecode. We found no Ableton Link or MIDI clock tempo input in it, so GHOST LINK can't set MADRIX's tempo yet.
  • Building your own: STATUS → OSC OUT sends the beat, BPM, the drop and crew calls as plain OSC to any computer. Mapping those to MADRIX is up to you. Untested.

SET IT UP

  1. Open the dashboard on the MADRIX computer (same Wi-Fi as the box).

  2. DECKS → LAYOUT → STACKED, and size the window into a corner.

TURN IT OFF

Close the window. If you set up OSC OUT: delete the line under STATUS → OSC OUT.

GHOST LINK never opens, edits or saves your MADRIX file, and sends nothing to it unless you list it under OSC OUT.
