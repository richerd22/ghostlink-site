SHARE THE TRACKLIST

Tonight's tracklist stays with the crew. Sharing shows it on WATCH FROM HOME, the link that works from anywhere. Ask the DJ first.

  1. Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  2. Open PLAYED.

  3. Tap TRACKLIST: CREW ONLY.

  4. It asks to make sure. Tap OK. The button now says TRACKLIST: SHARED.

Changed your mind? Tap it again. It goes back to crew only by itself the next night.

This button only shows on phones at the venue, never on the watch link.
