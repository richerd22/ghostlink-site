HELP / HOW TO

NAME A SET OR SAY WHOSE USB

When a new USB goes on air, the box starts a new set (SET 2, SET 3...). Give it a name, once.

NAME THE SET

  1. Open PLAYED. ON THE DECKS shows the current set.

  2. Type the DJ's name in the box next to it.

  3. Tap SET. Tonight's tracks from that set move under the name.

If the USB's own name looks like a person's, a button like ALEX? shows next to SET. Tap it to fill it in, then SET.

SAY WHOSE USB IT IS

  1. PLAYED → tap USBS TONIGHT to open it.

  2. Next to each USB, type whose it is.

  3. Tap SAVE.

Next time that USB starts a set, tonight or any night, GHOST LINK names it by itself.

These need the controls unlocked (password or crew code). A DJ's backup stick, or a B2B partner's, is never learned by itself.
