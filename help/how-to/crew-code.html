HELP / HOW TO

GIVE THE CREW CODE

A new 4-digit code every night. Give it to the lighting tech or a manager instead of the password.

  1. Unlock with the password (the owner password, not a crew code): STATUS → type it → UNLOCK.

  2. Under CONTROLS UNLOCKED it says CREW CODE TONIGHT and the 4 digits.

  3. Tell the crew member. On their phone: STATUS → type the code where it says password or crew code → UNLOCK.

It works until 10:00 the next morning. It unlocks the booth controls, but not the password, backups, the box's name or venue Wi-Fi passwords.
