HELP / HOW TO

USING GHOST LINK WITH QUICKSHOW

There's no ready-made QuickShow row. GHOST LINK sits beside it as a window; it sends nothing to QuickShow.

WHAT IT GIVES QUICKSHOW

  • The dashboard in a corner beside QuickShow: the decks, how long until the drop, who's next, crew calls.
  • We found no Ableton Link, MIDI clock or OSC tempo input in QuickShow, so GHOST LINK can't set its tempo. QuickShow's own beat detection stays as it is.

SET IT UP

  1. Open the dashboard on the laser computer (same Wi-Fi as the box).

  2. DECKS → LAYOUT → STACKED, and size the window into a corner.

  3. Want a heads-up before the drop? Pick NOW → LIGHTS: the section, what's next and bars to the drop, big.

TURN IT OFF

Close the window. GHOST LINK never touches QuickShow or its show files.

Untested with QuickShow. If your version takes Ableton Link, the ABLETON LINK row would work; tell us if it does.
