HELP / HOW TO

UPDATE THE BOX

New versions come by themselves over the box's internet. You choose when; the box never updates mid-set.

THE UPDATES CARD

STATUS, THE BOX, UPDATES (owner password). It says UP TO DATE, or NEW: and what's new in one line, with two choices:

  • UPDATE TONIGHT AFTER MUSIC OFF: the box gets it now and installs it by itself after the night, once the decks have been quiet 5 minutes. With no night planned it says UPDATE OVERNIGHT and waits for a quiet morning.
  • UPDATE NOW: tap, then hold. GHOST LINK restarts in about 20 seconds. Only there when nothing stops it.

WHAT'S NEW under it shows the notes of the new version, this one and the one before.

NEVER MID-SET

No update starts while a deck is playing, while a set is recording, or from 3 hours before tonight's planned start until MUSIC OFF or GOODNIGHT. The card says why, in one line.

AUTO-UPDATE

OFF: the box tells you, you choose when. QUIET HOURS ONLY: new versions install themselves after a night or on a quiet morning. It's off until you choose.

IF SOMETHING GOES WRONG

Only updates signed by GHOST LINK install, and they are checked before anything changes. A new version that doesn't start properly within a minute is undone by itself. The old version stays on the box: GO BACK TO puts it back, no internet needed.

FROM HOME

With WATCH FROM HOME you see the same card. To queue an update from home, make yourself a share link with UPDATE AFTER TONIGHT and ALSO FROM OUTSIDE THE VENUE ticked. That link can only queue it for after the night; it can never update on the spot. See SHARE LINKS.

NO INTERNET AT THE VENUE

Get the update file from support onto your phone, join the box's Wi-Fi, then INSTALL FROM FILE.
