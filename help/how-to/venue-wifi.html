ADD A VENUE'S WI-FI

Save it once. Next time the box is in range, it joins by itself, and phones stay on the venue's Wi-Fi with internet.

  1. Be on the dashboard (the GHOST LINK Wi-Fi is fine). Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  2. In STATUS → VENUE: tap NEW for a new venue, or pick it and tap EDIT.

  3. Type the venue's name.

  4. Tap + VENUE WI-FI. Type the Wi-Fi name exactly as it shows on your phone, and the password.

  5. More than one Wi-Fi there (staff, booth)? Tap + VENUE WI-FI again for each.

  6. Tap SAVE.

The box joins it within about a minute when it's in range. The green light goes solid. Phones then join the venue Wi-Fi and open ghostlink.local or gl.cold.fyi.

Passwords stay on the box and only show on unlocked phones. To keep a saved password while editing, leave the password box blank.
