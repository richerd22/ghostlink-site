RECORD A SET

With a small USB sound card, GHOST LINK records a set from the mixer, with its tracklist. Nothing is ever recorded unless you choose to, set by set.

ONCE: PLUG IN THE CARD

  1. Plug the sound card into a USB port on the box. See gear to buy.

  2. Run an RCA cable from the mixer's REC OUT to the card's INPUT. REC OUT already used? A Y-splitter.

  3. Open NETWORK → SOUND IN. Play music: the meter moves. Aim for the loud parts around -12 dB.

EACH SET YOU WANT

  1. Ask the DJ first. It's their set.

  2. Check PLAYED → ON THE DECKS says the right name.

  3. Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  4. NETWORK → SOUND IN → ● RECORD (it shows the DJ's name).

  5. A red ● REC shows at the top of every screen while it records.

It stops by itself when the next DJ is on the decks, at the end of the night, or after 10 minutes of silence. The next DJ is never recorded unless you tap ● RECORD again. Anyone at the venue can tap STOP RECORDING, no password.

Afterwards, under SET RECORDINGS: the lossless file to download and its TRACKLIST with times (unlocked phones). The box makes room by itself when it runs low, oldest first.

The card also gives a SILENCE warning when the room goes quiet, even on a night with no DJ network at all.
