HELP / HOW TO

RECORD A SET

With a small USB sound card, GHOST LINK records a set from the mixer, with its tracklist. Nothing is ever recorded unless you choose to, set by set.

ONCE: PLUG IN THE CARD

  1. Plug the sound card into a USB port on the box. See gear to buy.

  2. Tap SET UP on the SOUND CARD FOUND line (or NETWORK → SOUND IN → SET UP GUIDE). It says which output on your mixer, checks the level and makes a 10-second test recording: the steps.

EACH SET YOU WANT

  1. Ask the DJ first. It's their set.

  2. Check PLAYED → ON THE DECKS says the right name.

  3. Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  4. NETWORK → SOUND IN → ● RECORD (it shows the DJ's name).

  5. Pick what to record: THIS SET (already picked), THE NEXT 2, 3 or 4 SETS, or ALL NIGHT. For more than one set, pick how to save it: ONE FILE PER SET, ONE FILE FOR THE NIGHT, or BOTH. Then ● START RECORDING.

  6. A red ● REC with the time shows at the top of every screen while it records. Tap it to see who started it, how long it's been going, and to stop it.

More than one set is kept as one file with a mark at each new DJ (and each long quiet stretch). You get a file per set when you export, and you can move the marks first. With THE NEXT 2 SETS it stops two minutes into the third set, so the second one is never cut; KEEP RECORDING adds one more.

It keeps going until someone taps ■ STOP RECORDING. It never cuts you off: if the DJ, the USB or the set time changes, it carries on and asks NEW FILE (a separate file from here) or KEEP GOING (one file). Anyone at the venue can tap STOP RECORDING, no password.

NEVER FORGET TO STOP

When the music is off for the night (your MUSIC OFF time) and the room has gone quiet, every screen says MUSIC'S OFF · STILL RECORDING with ■ STOP NOW and KEEP RECORDING. If nobody taps, it stops by itself 15 minutes after music off, but only once it's quiet: a set that runs late is never cut. Change that in ALL SETTINGS → RECORDING: STOP BY ITSELF AFTER MUSIC OFF (REMIND ONLY, 5, 15 or 30 minutes). With no music off time it reminds you after 5 quiet minutes, and stops after 10 (30 when it's recording more than one set). Want the room to see it? RECORDING: ● REC ON THE TV puts a small ● REC on the TV page.

While it records, the box keeps an ear on the level. TOO HOT means the recording is hitting the top; TOO QUIET means it's low. If you tapped the jack you used in SET UP SOUND IN, the warning names it and the knob that sets it (on MASTER 2 that's the MASTER knob, which moves the room too). Each is said once and clears by itself once the level is right. SOUND IN also says about how many hours of room are left, and warns early when it's under an hour.

GET THE FILE

Under SET RECORDINGS (unlocked phones): TRACKLIST with times, FLAC (lossless), MAKE MP3 (320, made on the box in a minute or two, with a marker at each track) and CUE (a cue sheet for the FLAC). Leave TRIM THE QUIET AT THE START AND END ticked to cut the silence off the MP3; the FLAC is never changed. The box makes room by itself when it runs low, oldest first.

When a recorded set ends, the box makes its MP3 by itself, slowly, and never while another set is recording, so it's ready to hand over. Turn that off in ALL SETTINGS (AUTO MP3 AFTER EACH SET). Each recording shows a small strip of its level over the set; an amber mark is a moment it clipped.

TRIM, SPLIT, EXPORT

  1. On a saved recording, tap TRIM · SPLIT · EXPORT.

  2. The picture is the recording's level. Tap it to put the cursor there; ▶ PLAY 12 S HERE to listen. Drag the white lines for the start and end, the red lines for where each set starts (or use AT CURSOR and the -1 S / +1 S buttons). + SPLIT HERE adds a set; type who it is.

  3. FADE IN and FADE OUT: off, 2, 5 or 10 seconds. ▶ HEAR IT plays the start or the end as it'll sound.

  4. SAVE THE EDIT. The original FLAC is always kept as it was recorded; BACK TO THE BOX'S GUESS undoes your edit.

  5. Pick a format: WAV (16 or 24-bit), AIFF, FLAC, MP3 320 or V0, or M4A, at 44.1 or 48 kHz, then MAKE for the whole night or each set. Each one says about how big it'll be. CUE and TRACKLIST give that file's track times.

  6. When it's made, DOWNLOAD. Big files come over the box's Wi-Fi; if it drops, the download carries on from where it stopped.

Files are named like 2026-11-25 - TICK - 22.15-02.02.wav. The box makes them slowly, one at a time, and never while a set is recording (they wait until it ends). A 3 hour 46 minute night is about 2.6 GB as WAV, 1.5 GB as FLAC and 540 MB as MP3 320.

MIXCLOUD CHECK

While a set records, NOW can say MIXCLOUD CHECK · fits Mixcloud's rules so far. Tap WHAT'S THIS? for the details. Mixcloud's rule for a show: no more than 4 tracks by one artist (3 in a row) and no more than 3 from one album or EP (2 in a row). A show that breaks it still goes up, but only subscribers can play it. GHOST LINK counts only the tracks it saw on the decks. The same sheet says how SoundCloud, YouTube, Twitch and Instagram handle music in a set. It's a heads-up, not legal advice.

HAND IT TO THE DJ

  1. Owner's password: on the recording, tap HAND IT TO THE DJ → MAKE THE LINK.

  2. The DJ scans the code (or you COPY the link to them). They get that one recording as an MP3, and its tracklist if they shared it.

  3. Their page also shows YOUR SET: how long, how many tracks, the BPM journey, the keys (and a little key wheel), mixes, the longest blend, how clean the blends were, and the peak-time track (playing in the loudest minute). And their SET DNA picture to save and post (no track names on it).

  4. It works on the box's Wi-Fi for 7 days. Tick ALSO FROM OUTSIDE THE VENUE first if they'll download it at home (needs WATCH FROM HOME). REVOKE ends it sooner.

The card also gives a SILENCE warning when the room goes quiet, even on a night with no DJ network at all.
