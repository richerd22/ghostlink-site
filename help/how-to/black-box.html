HELP / HOW TO

DOWNLOAD THE BLACK BOX

The black box is the box's own log of the night. Handy when something odd happened and you want to know when and why.

  1. Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  2. STATUS → CONTROLS → BLACK BOX.

  3. A zip downloads: the logs and the played lists.

Send it with a note of roughly what time the odd thing happened to hello@thirdpolararch.com if you'd like us to look.
