PLAN A NIGHT

Enter it once. On the night, the box picks the venue and puts tracks under the right DJ by itself.

  1. Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  2. STATUS → NIGHTS → PLAN TONIGHT (PLAN A NIGHT once tonight is planned). Or tap TAP TO PLAN on NOW, or press P on a laptop.

  3. Pick the date and the venue.

  4. STARTS: when the night begins, like 22:00. Music before that is SOUNDCHECK.

  5. MUSIC OFF: optional, like 2:00.

  6. Lineup, one act per line, time first: 22:00 OPENER, 23:30 HEADLINER, 01:00 CLOSER. No times? One line with the night's name or the one artist playing all night. Pasting from a flyer works too: 10pm OPENER, 10-11pm OPENER, OPENER 22:00. The READS AS line under the box shows how each line will be saved. A note for the crew goes after the name with two slashes: 23:30 LIL TICK // NEEDS TT + MIC (40 letters; it shows in the NIGHTS list, on the crew screen and on the stage clock near the changeover). Same lineup as last time at this venue? Tap SAME LINEUP AS.

  7. Tap SAVE.

On the night, each DJ takes over when their first track goes on air from a new USB, or 15 minutes after their time if no new USB shows. A SET by hand in PLAYED wins until the next slot.

Planning a date that already has a plan asks before replacing it; to change a night, use EDIT on it.

Times before noon count as the same night: 01:00 is after midnight.

Running late? RUNNING LATE? on NOW moves every set that hasn't started by 5 or 10 minutes (UNDO puts it back; any other number is in PLAYED). MUSIC OFF stays. If the HARD STOP app sent tonight's lineup, it moves the times there instead and the button isn't shown.

Near the end of a set, the deck you've loaded says FITS or RUNS 1:20 OVER on its own tile. In PLAYED, NOT A NEW SET fixes a wrong changeover on any night, not just tonight.

MOMENTS

For a wedding, a party or a show with a walk-on: the box under the notes takes the night's moments, one a line, like 21:30 SPEECHES // mic 2 on or 22:15 FIRST DANCE (up to 12; the note after // is for the crew). In each one's last 30 minutes the screens say SPEECHES IN 12. It never plays anything. To have each one call the crew a minute before (a countdown on the panels, crew screen and TV, the name only): ALL SETTINGS → A MOMENT SENDS ITS CREW CALL. Off until the owner turns it on. SET TIMES FROM A SHEET

Set times already in a spreadsheet? Bring them in instead of typing.

  1. STATUS → NIGHTS → SET TIMES FROM A SHEET. Pick the night.

  2. PASTE: copy the cells straight out of the sheet (or a CSV) and paste them. Or SHEET LINK: in Google Sheets, File → Share → Publish to web, pick the tab and CSV, and paste that link.

  3. Tap PREVIEW. Check the times: rows it couldn't read are listed with why.

  4. Tap USE THESE TIMES. The lineup shows in NIGHTS like one you typed. UNDO puts back what was there.

Columns: a start time, an end time (optional) and the DJ. The headings can be called almost anything (Set time, Artist, Until), and a date column keeps only that night's rows. 22:00, 10pm, 10:30 PM and 22:00-23:30 all work; 1:00 after 23:00 is after midnight.

With a link, the box reads the sheet again every 5 minutes that night, so a change made in the sheet shows up by itself. STOP FOLLOWING keeps the times and stops reading. Typing over the lineup by hand also stops it.

If HARD STOP sends tonight's lineup, HARD STOP's wins, and this part just says Set times come from HARD STOP tonight.
