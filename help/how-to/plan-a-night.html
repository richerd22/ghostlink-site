PLAN A NIGHT

Enter it once. On the night, the box picks the venue and puts tracks under the right DJ by itself.

  1. Unlock first, if this phone isn't already: STATUS → type the password (or tonight's crew code) where it says password or crew code → UNLOCK.

  2. STATUS → NIGHTS → PLAN A NIGHT.

  3. Pick the date and the venue.

  4. STARTS: when the night begins, like 22:00. Music before that is SOUNDCHECK.

  5. MUSIC OFF: optional, like 2:00.

  6. Lineup, one act per line, time first: 22:00 OPENER, 23:30 HEADLINER, 01:00 CLOSER. No times? One line with the night's name or the one artist playing all night.

  7. Tap SAVE.

On the night, each DJ takes over when their first track goes on air from a new USB, or 15 minutes after their time if no new USB shows. A SET by hand in PLAYED wins until the next slot.

Times before noon count as the same night: 01:00 is after midnight.
