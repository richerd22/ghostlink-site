FAQ

Short, honest answers.

DOES IT TOUCH THE DECKS OR THE SOUND?

Not unless you ask it to. Out of the box it listens to the DJ network and never sends a command to a player or mixer. The one exception is DECK CONTROLS (stop, play, load a track), which stay off until the owner turns them on. Nothing passes through it, so if it dies the booth carries on. It joins on a spare number (7 to 15) and if anything else wants that number, it steps aside by itself.

WHAT CAN PEOPLE SEE? WHAT'S PRIVATE?

Anyone on the same Wi-Fi as the box can open the dashboard and watch: decks, NOW, PLAYED. Changing anything needs the password or tonight's crew code. Away from the venue, WATCH FROM HOME shows the decks but not the tracklist, unless the DJ says yes. Venue Wi-Fi passwords stay on the box. It doesn't copy anyone's music: it reads the track details the players share on the network. If the box sits on a Wi-Fi the public uses, anyone there who finds the address can watch too; use the GHOST LINK Wi-Fi if that matters.

NO MIXER ON THE NETWORK?

It still works. Without the mixer it can't tell which deck is out loud, so: ON AIR isn't shown, PLAYED guesses from the MASTER deck (a track counts after 30 seconds), dead-air goes by what's playing, and fader info is missing. STATUS says so once; OK, NOT TONIGHT puts the note away on that phone. Cable the mixer's LINK port to the same switch to get it all back.

WHAT IF THE WI-FI DROPS?

The music is never affected. The box keeps reading the decks and keeps writing PLAYED and the black box. Phones show Lost connection to GHOST LINK and reconnect by themselves. The box looks for a Wi-Fi it knows every 15 seconds; after 10 minutes with none, it becomes the GHOST LINK Wi-Fi so phones can still reach it. Phones that were away see WHILE YOU WERE AWAY.

CAN I JUST UNPLUG IT?

Yes. That's the normal way to switch it off. It can't hurt it. Plug it back in and it comes back up. See turn it off.

DOES IT NEED INTERNET?

No. Everything runs on the box. Internet only adds the short link, WATCH FROM HOME, and a correct clock straight away.

DO PEOPLE NEED AN APP?

No. Any phone browser.

WHICH GEAR DOES IT WORK WITH?

Players and mixers on a PRO DJ LINK network: CDJs, XDJs and DJMs with a LINK port. Tested with XDJ-XZ and CDJ-3000 setups. Older LINK players should show up the same way, but some don't share everything: song sections need a recent player, and the XDJ-XZ doesn't send them. See KNOWN ISSUES.

WHERE DOES THE DATA COME FROM?

From the PRO DJ LINK network your players and mixer already use to talk to each other: what's loaded, playing and on air, tempo, beats, and the track details the players share (title, artist, key, waveform and sections from rekordbox analysis). GHOST LINK reads it with beat-link, an open-source library by Deep Symmetry built by studying that network (Beat Link Trigger works the same way).

What that means: Pioneer DJ / AlphaTheta haven't published this protocol and haven't certified GHOST LINK. A player firmware update can change something before we catch up; KNOWN ISSUES says when it does.

What it doesn't do: it doesn't copy or read your music files, doesn't need rekordbox running, and keeps only what went on air (and a set recording, only when you choose one). Out of the box it only listens; deck controls stay off unless you turn them on.

With a USB sound card, it also hears the mixer's REC OUT: the actual sound, not just the data.

WHAT ABOUT LAPTOPS, SERATO OR CONTROLLERS?

GHOST LINK reads the DJ network. Players in laptop or controller mode (Serato, rekordbox over USB to a laptop) don't talk on it, so those decks don't show. DJs playing from USB on the other decks still do. Nothing to change for the laptop DJ. A mixer with no network port (a DJM-S9, for example) doesn't show either; the decks still do if they're linked to each other.

WHAT'S THE PASSWORD?

The one on the sticker on your box. Change it to your own in STATUS → CHANGE PASSWORD. For crew, give tonight's crew code instead.

GHOSTLINK.LOCAL WON'T OPEN.

Some phones and guest Wi-Fi don't do .local. Tap GHOST LINK at the top of the dashboard on a phone that works for the number address and a QR, or use gl.cold.fyi. On the GHOST LINK Wi-Fi it's always 10.42.0.1.

WHAT'S THE AMBER GHOST?

Backed off. Another device used GHOST LINK's number, so it stepped off the network. It comes back on a free number in about 30 seconds. Nothing to do.

IT'S HOT.

It has no fan. STATUS warns when it's too hot. Give it air: not on an amp, not in a closed bag.
